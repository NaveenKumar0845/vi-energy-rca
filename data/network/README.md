# Optional network KPI data

Do **not** commit proprietary network KPI extracts.

For local/private testing, an optional `network_kpis.xlsx` may be placed here. Supported fields can include RSRP, RSRQ, SINR, DL/UL throughput, PRB utilization, availability and alarm count. Git ignores files in this folder except for this README.

Without real network KPI evidence, the application should be described as an energy/billing dispute RCA solution rather than a full 5G RF-performance RCA system. The public demo uses synthetic KPI records solely to demonstrate the join and evidence flow.
