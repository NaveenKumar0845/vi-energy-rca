# Processed data

Do **not** commit proprietary processed workbooks.

For local/private testing, an optional `filtered_data.xlsx` can be placed here on your local clone. Git ignores files in this folder except for this README.

Expected minimum columns:

`IP Site ID`, `Expense Nature`, `Month-Year`, `Prorated Billed Amount (Excl GST)`.

The public demo creates its analytical dataset in memory from synthetic raw data.
